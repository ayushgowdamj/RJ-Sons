# RJ SONS

Showcase website for RJ SONS — saree and dhoti manufacturing, curated collections, loom craftsmanship, and custom design briefs.

## Tech Stack

- React 19 & TypeScript
- Vite 8
- Tailwind CSS v4

## Getting Started

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
pnpm preview
```
